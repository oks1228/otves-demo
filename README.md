# Отвес — демо

Расчёт стоимости строительства и коммерческое предложение (КП) в PDF.
Открыть: https://oks1228.github.io/otves-demo/

Демо работает в браузере без сервера: объекты и настройки хранятся только
в вашем браузере и никуда не отправляются. Делайте копию кнопкой «Сохранить в файл».

Здесь лежат только собранные файлы; сборка 8f05bd3.
