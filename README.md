# Отвес — демо (закрыто)

Демо-версия закрыта 15.10.2026. «Отвес» теперь называется «Абрис» и работает на сайте https://otves.online
(бесплатно на время тестирования).

Страница https://oks1228.github.io/otves-demo/ предлагает скачать данные демо, оставшиеся в браузере,
чтобы перенести их в рабочую версию: «+ Новый объект» → «Или загрузить: … из демо-версии».
